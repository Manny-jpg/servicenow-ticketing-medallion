## Reading the samples

- Each layer is a separate extract, so row sets overlap rather than match one-to-one (for example, 971 incident numbers appear in all three layers). Row counts between layers are therefore not a measure of what a filter removes.
- Timestamps in bronze are **UTC**; silver and gold are **US/Eastern** for the incident and SLA tables. The survey tables have no timezone conversion.
- `dimdate.csv` is generated by the `DimDateWorkday` function in the incident notebook (2025-03-01 onward; weekends and US holidays are marked `Workday = False`).
- `asmt_*` files are the survey tables from `02_survey_pipeline.ipynb`. The silver questions table is saved as `asmt_question_silver` (singular) in the notebook. There is no `asmt_question_gold` sample, and `asmt_type_bronze.csv` is a raw reference table not used by the notebooks.
